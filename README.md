# Python Crash Course – Exercises & Projects

This repository contains my solutions, exercises, and hands-on practice from the book ***Python Crash Course* by Eric Matthes**.

The goal of this repository is to document my journey of learning and strengthening Python through practical programming exercises, problem-solving, and progressively more advanced projects.

## 📚 About the Book

**Python Crash Course** is a hands-on introduction to Python programming that covers the fundamentals of the language and gradually introduces more advanced concepts through practical projects.

The exercises in this repository follow the concepts and progression presented in the book.

## 🚀 Running the Exercises

### 1. Clone the repository

```bash
git clone https://github.com/zetacoder/python_crash_course
```

### 2. Navigate to the repository

```bash
cd python-crash-course
```

### 3. Verify Python installation

```bash
python --version
```

or:

```bash
python3 --version
```

### 4. Run an exercise

Navigate to the appropriate chapter and run the Python file:

```bash
3_2_greetings.py
```

For example:

```bash
python 1_Basics/3_Introducing_Lists/3_2_greetings.py
```

## 🧪 Running Tests

Where exercises include automated tests, they can be executed using `pytest`:

```bash
pytest
```

For a specific test file:

```bash
pytest test_name.py
```
